# Trabajo Final Integrador - Frontend
### Asignatura: Programación y Servicios Web
### Facultad de Ingeniería – Universidad Nacional de Jujuy (UNJU)

Este repositorio contiene la interfaz de usuario (Frontend) para el Sistema de Gestión de Compraventa (E-commerce). Está desarrollado como una aplicación de página única (SPA) modularizada y con un diseño completamente responsivo.

---

## Tecnologías Utilizadas
 **Framework:** Angular 
 **Estilos y Layout:** Bootstrap 5 & CSS3
 **Gestor de Paquetes:** NPM
 **Librerías Visuales:** Ng2-charts (Chart.js) / DataTables
